# Mario AI — ルールベース & モンテカルロ法によるマリオ自動プレイ

[Mario AI Benchmark](http://julian.togelius.com/mariocompetition2009/)（Javaで作られたマリオのクローン）の上で、マリオを自動でプレイするエージェントを作りました。

| 項目 | 内容 |
|---|---|
| 開発形態 | 個人開発 |
| 背景 | 大学の実験（計算機科学実験及演習2）の一環として実装 |
| 言語 | Java |

- **ルールベースのエージェント**：周りのブロックや敵を見て、ジャンプやダッシュを判断する
- **強化学習のエージェント**：モンテカルロ法で行動価値関数を学習し、ステージの右端（ゴール）を目指す

## モンテカルロ法エージェントの設計

- **状態**：マリオの前方2マス × 縦3マスにある障害物・敵の有無をビットで表したもの ＋ 地面にいるか・ジャンプできるか・前に崖があるか・壁があるか
- **行動**：ジャンプ / ファイア / 右 / 左 / 下 の組み合わせの18通り
- **方策**：ε-greedy（ε = 0.05）。基本は行動価値が最大の行動を選び、確率εでランダムに選ぶ
- **更新**：1エピソードが終わったら、そのエピソードで通った (状態, 行動) の組それぞれに得られた報酬を足し、平均を行動価値とする（first-visitのモンテカルロ法）
- **報酬**：マリオが進んだ距離からペナルティを引いた値。それまでの最高記録に届かなかったエピソードは、記録との差に応じて報酬を下げる
- **リプレイ**：学習中に一番良かった行動列をファイルに保存し、あとで再生できるようにした

### 工夫した点：そそり立つ壁を越えるための停止ペナルティ

- **課題**：ステージの途中にそそり立つ壁があり、「右に進むほど報酬が高い」という報酬設計だけでは、壁の前で右に押し続ける行動から抜け出せず、学習がうまく進まなかった。
- **対策**：一定時間、進んだ距離が増えないとペナルティが溜まる仕組みを入れた（`MCAgent.evaluateStop`）。止まっているとペナルティが増え、前に進めば減る。ペナルティが一定値を超えたら一時的に行動の割り当てを切り替え、ジャンプや左への移動を試して行き詰まりから抜け出すようにした。

## ルールベースエージェントの工夫（Task3Agent）

- 前方1〜3マスにある障害物と、足元の穴を見つけてジャンプする
- 敵の位置を、マリオから見た**距離と角度**で判定する
  - 正面上方の近くに敵がいたらジャンプ
  - 斜め前に敵がいたらダッシュを止める、など状況によって行動を変える

## 実行方法

Eclipseでこのフォルダを既存のJavaプロジェクトとして読み込みます（`lib/` のjarはクラスパスに設定済みです）。

- ルールベース：`ch.idsia.scenarios.MainTask2` / `MainTask3` を実行
- モンテカルロ法の学習とリプレイ：`ch.idsia.scenarios.champ.LearningTrackMC` を実行
